- До заморозки цепочка и UI — на чипе validation `Sri-Lanka_713926`; демо-чип из test
  (`Spain_7370579`) — после заморозки, только S1; метки test — только `eval-test` (D-010).

  на validation).
- Постобработка применяется к p, а не к маске: mask ⇔ p ≥ порог всегда.
