## Доли меток, NaN и VV > 0 dB по частям разбиения

Доли −1/0/1, NaN и VV > 0 dB — от всех 512×512 пикселей чипа, среднее по чипам (= доля пикселей части). NaN — по VV (NaN в VV и VH совпадают, `docs/data.md` §11). «Вода среди размеченных» = Σ(1) / Σ(0 + 1). «Без валидных» — нет ни одного пикселя с конечным S1 и меткой ≠ −1. «NaN S1 под 0/1» — S1 не конечен хотя бы в одном канале, а метка 0 или 1 (ловушка набора: маска валидности = S1 конечен **и** метка ≠ −1). VV > 0 dB — доля от всех пикселей (NaN не > 0). `excluded` — 5 чипов Ghana, целиком −1 (D-016).
