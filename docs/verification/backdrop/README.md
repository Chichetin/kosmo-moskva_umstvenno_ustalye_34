# Динамический фон глобуса (`web/src/Backdrop.tsx`) — нагрузка

Проверка 26.09.2026. Ноутбук Intel Core Ultra 200V, GPU Intel Arc 140V (Mesa). Headless Chromium
с аппаратным GPU (`--use-gl=angle --use-angle=gl`, рендерер `ANGLE (Intel, Mesa Intel(R) Graphics
(LNL), OpenGL ES 3.2)`), окно 1440×900. Сравниваются две сборки `vite build` под `vite preview`
с одним и тем же API (`make site` на :8000): `origin/main` до фона и ветка с фоном.

Порядок на каждый прогон: страница открывается, 9 с на загрузку глобуса (фон начинает двигаться
через 2,5 с). Затем:
- **покой** — 10 с без ввода; считаются кадры `requestAnimationFrame` и CPU всех процессов
  браузера (utime+stime из `/proc/<pid>/stat` по процессам с этим профилем);
- **вращение** — 6 с синтетического перетаскивания глобуса (`mousedown` → `mousemove` на каждом
  кадре → `mouseup` по холсту MapLibre); те же метрики.

`long` — кадры длиннее 33,4 мс, `p95` — 95-й перцентиль интервала кадров, мс.

| main | 60.2 | 3 | 60.2 | 16.8 | 0 | 49 |

| main | 60.2 | 8 | 60.2 | 16.8 | 0 | 50 |

Итог: при вращении карта держит 60 fps с фоном и без него, длинных кадров нет, CPU одинаковый.
В покое разница в пределах разброса прогонов main (3–9 %).

Как пришли к этой схеме (те же условия, CPU в покое):
- первая версия — пятна CSS-анимацией на трёх слоях больше экрана плюс каустика в отдельном
  canvas: 27–32 % против 10–13 % у main. Основную цену давал композитинг трёх анимированных
  полноэкранных слоёв на 60 fps;
- пятна, параллакс и каустика в одном непрозрачном canvas при 30 fps: 13–14 %;
- то же при 20 fps (итог): 9–10 %. Все циклы движения — 24–88 с, поэтому 20 fps на глаз
  не отличаются от 30.

Защиты в коде: `prefers-reduced-motion` и программный рендер (SwiftShader, llvmpipe, Microsoft
Basic Render) — статичный кадр; скрытая вкладка, сцена и экран «Анализ» — цикл остановлен;
первые 30 кадров дольше 20 мс (5 раз) или 45 кадров подряд позже 100 мс — статичный кадр;
без WebGL — прежний CSS-градиент. Экран «Анализ» попиксельно совпадает с main (разница 0).

Кадры: `before-earth-*.jpg` — main, `after-earth-*.jpg` — ветка, `after-t00s/t10s/t20s` — один
прогон с интервалом 10 с (средняя разница яркости угла без панелей 1,6 и 3,1 уровня из 255).
