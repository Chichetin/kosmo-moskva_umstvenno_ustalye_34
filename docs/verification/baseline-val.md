# Baseline: порог по S1 — проверка на dev и validation

Сгенерировано `make baseline` (commit `b7445cb0baf5`, 2026-09-25). Числа ниже — из `docs/verification/baseline-metrics.csv`, `baseline-variants.csv`, `baseline-threshold-curve.csv`. Test не читался (D-010).

## Правило

- Вода ⇔ **VV ≤ -16.5 dB** (S1 уже в dB). Порог — максимум IoU по всем валидным пикселям train (пулинг пикселей), перебор от −60 до +30 dB с шагом 0,1.
- Канал выбран на train: VV: порог -16.5 dB, IoU train 0.381; VH: порог -23.0 dB, IoU train 0.378.
- Вероятность (временный основной метод, D-009): p = sigmoid((-16.5 − VV) / s), **s = 2.179 dB** — минимум log-loss на train при фиксированном пороге. p ≥ 0,5 ⇔ маска baseline. Сигмоида не калибрована на validation: доля воды в train 8,9 %, в validation 15,2 %.
- Валидный пиксель: VV и VH конечны **и** LabelHand ≠ −1 (`floodvalue.model.metrics`). `valid_mask_sha256` — отпечаток этой маски; основной метод обязан получить тот же хеш.
- Чипов: train 237, dev 69, validation 60.
